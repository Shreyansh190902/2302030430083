# Wudly × Diwali – Crack Code "Code Crack Karo, Mithai Pao" Reel Script
**Shoot:** 31 October · **Talent:** Mother + son · **Length:** 20 sec · 9:16
**Product:** Wudly Wooden Crack Code Educational Toy · 10+ years · Rs. 1,499 (MRP Rs. 1,649)
**Link:** https://www.wudlytoys.com/products/wudly-wooden-crackcode-educational-toy-for-kids

**Idea:** Mom hides a secret colour code behind the Crack Code screen and puts a box of kaju katli next to it. The deal: crack the code, win the mithai. The son guesses row by row, Mom gives hints, he cracks it – the screen comes down and the mithai is his.

*Age note: Crack Code is rated 10+. If the son is younger, Mom guides him with easy hints – don't claim it's for younger kids in text or caption. Follow the hint rules on the game's own instruction card.*

---

## Set & props
- Crack Code board + all pegs, a small box of kaju katli (or a wrapped Wudly gift), marigolds, LED diyas, fairy lights
- Outfits: Mom red/cream saree or kurta, son mustard/cream kurta
- Camera: tripod eye-level + overhead arm · 60 fps for slow-mo close-ups

---

## Screenplay

**SCENE 1 – THE DEAL**
*(Close-up: Mom places the secret pegs behind the screen ("Let's crack the code!") and sets a box of kaju katli beside the board.)*
**Mom:** *(smiling)* "Code crack karo… aur kaju katli tumhari!"
**Son:** *(shakes her hand)* "Deal!"
📱 Text: **Crack the code, win the mithai 🔐🍬**

**SCENE 2 – GUESSING (OVERHEAD, QUICK CUTS)**
*(Son places a row of coloured pegs – wooden "tock" sounds. Mom checks behind the screen.)*
**Mom:** "Do colour sahi… par jagah galat!"
**Son:** *(thinking face)* "Hmm…"
📱 Text: **Think 🤔**

**SCENE 3 – GETTING CLOSE**
*(Second row, faster. Mom raises her eyebrows. Tick-tock sound effect, light zoom on son's face.)*
**Mom:** "Bas ek galat hai…"
📱 Text: **Guess 🎯**

**SCENE 4 – CRACKED! (60 FPS)**
*(Slow-mo: son places the last peg with confidence. Mom lowers the screen – the codes match.)*
**Son:** *(arms up)* "Crack kar diya!"
**Mom:** *(hands over the box)* "Deal is deal!"
📱 Text: **CRACKED IT! 🎉**

**SCENE 5 – SWEET WIN**
*(Son takes a bite of kaju katli, offers one to Mom. Both laugh; diyas glow behind.)*
**Mom (voice-over):** "Is Diwali, mithai bhi dimaag se kamaao."
📱 Text: **Brains + sweets = Happy Diwali 🪔**

**END CARD (3 sec)**
*(Red Wudly card · Crack Code product shot · logo top-right.)*
📱 Text: **Crack Code · Logic game · Rs. 1,499 · wudlytoys.com**

## Director tips
- Choose an easy code (e.g. 3–4 colours, no repeats) so he can crack it in 2–3 rows on camera.
- Play for real and keep rolling; re-shoot only the final peg in slow-mo.
- Keep the mithai box closed until the win so it stays a surprise.
- Clean "tock" sound of pegs – fan/AC off, mic close to the board.
- LED diyas only near the board.
- Get signed parent consent before filming.
